# Emacs Configuration

This is my configuration for Emacs 31.1+ running on MacOS. The easiest
way to use this is to clone the repository into your ~/.config
directory:

``` shell
cd ~/.config
git clone https://github.com/BlameTroi/config-emacs.git emacs
```
